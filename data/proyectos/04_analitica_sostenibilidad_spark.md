# Caso de Estudio: Procesamiento Distribuido con Spark y Analítica de Sostenibilidad

## Rol y Responsabilidad
- **Posición:** Desarrollador Big Data y Backup de Data Scientist.
- **Entorno:** Apache Spark, Python, HDFS, Plataforma ADA.

## Situación y Reto
Requerimiento de centralizar, limpiar y transformar grandes volúmenes de datos transaccionales para generar indicadores cuantitativos sobre el eje estratégico de sostenibilidad corporativa.

## Acciones Ejecutadas
- **Ingeniería de Datos Distribuida:** Diseño y desarrollo de procesos ETL complejos y flujos analíticos optimizados utilizando Apache Spark y Python dentro de la plataforma corporativa ADA.
- **Modelado Analítico Avanzado:** Apoyo en el rol de Científico de Datos para diseñar, ajustar y evaluar modelos de estimación y comportamiento relacionados con sostenibilidad.
- **Extracción de Evidencia Empírica:** Minería y estructuración de datos para sustentar la toma de decisiones estratégicas del negocio y medir el impacto tangible en clientes.

## Resultados e Impacto
- Masterización confiable de datos masivos para auditorías y tableros directivos.
- Automatización del flujo de datos de extremo a extremo, reduciendo los tiempos de cómputo sobre datasets distribuidos.
